# Code de conduite

Nous voulons un projet accueillant. Soit respectueux·se, constructif·ve et patient·e, y compris avec les débutants.
Pas de harcèlement, d'insultes, de discrimination ni de publication d'informations privées d'autrui.

Les mainteneurs peuvent modérer ou supprimer toute contribution ou tout commentaire contraire à ces règles, et
écarter leurs auteurs. Pour signaler un problème, utilise le signalement privé de GitHub ou contacte un mainteneur.

Ce code s'inspire de l'esprit du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
